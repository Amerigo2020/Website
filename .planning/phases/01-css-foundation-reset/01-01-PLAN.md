<objective>
Remove all three competing CSS sources from index.php, eliminating the PHP color injection system and all inline style/script blocks that currently override app.css and force a light-mode render.

Purpose: The site currently renders light because a bare `<style>` block (index.php lines 1218–1251) injects `--color-background: #F7F7FF` after app.css loads, overriding every dark token. This plan removes that override and every related artifact — PHP `$colors[]` array, the ~950-line `media="not all"` style duplicate, the theme-init script, the theme toggle button, the theme toggle JS, the canvas element, and the WebGL animation script.

Output: A clean index.php where the only CSS authority is the `<link>` to app.css.
</objective>
