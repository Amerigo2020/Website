
<task type="auto">
  <name>Task 2: Add CSS grid background (body::before) and JetBrains Mono scoped rules; delete stub JS files</name>
  <files>client/src/assets/css/app.css</files>
  <action>
Open app.css (already rewritten by plan 01-02). Find the body rule that was added immediately after :root. After the body rule, add the body::before grid and the body > * stacking rule:

```css
/* Grid background — replaces WebGL canvas, zero JS, zero GPU */
body::before {
  content: '';
  position: fixed;
  inset: 0;
  background-image:
    linear-gradient(rgba(255,255,255,0.025) 1px, transparent 1px),
    linear-gradient(90deg, rgba(255,255,255,0.025) 1px, transparent 1px);
  background-size: 40px 40px;
  pointer-events: none;
  z-index: 0;
}

/* Ensure all page content sits above the grid */
body > * {
  position: relative;
  z-index: 1;
}
```

Do NOT increase the rgba opacity above 0.025. Higher values produce a graph-paper look instead of a subtle texture.

Then find or add JetBrains Mono scoped rules. Search app.css for `.eyebrow`, `.logo`, `.chip--date`, `.capability-label`, `pre`, `code`. For each selector that exists, ensure `font-family: var(--font-mono)` is set. If any selector does not exist yet, add a minimal rule:

```css
/* JetBrains Mono — technical labels only */
.eyebrow,
.capability-label,
.chip--date,
.logo,
pre,
code {
  font-family: var(--font-mono);
}
```

If individual rules for these selectors already exist in app.css, add `font-family: var(--font-mono)` to each rather than creating duplicates.

Do NOT apply --font-mono to: body, h1, h2, h3, p, button, label, input, textarea, footer, nav links, or service descriptions.
