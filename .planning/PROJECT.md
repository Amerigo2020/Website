# Velletti — Personal Brand & Consulting Site

## What This Is

A personal branding and consulting website for a software developer (Business Informatics student at TUM) who builds complete systems for startups and small businesses. The site positions the developer as a trustworthy, technically deep individual — not a faceless agency — and converts cold and warm visitors into clients through genuine story and personality.

## Core Value

A cold visitor should finish reading and think: *"I trust this person"* — and immediately know how to reach out.

## Requirements

### Validated

- ✓ Contact form — existing
- ✓ Stripe payment integration — existing
- ✓ Basic services/landing page structure — existing

### Active

- [ ] Rewrite narrative voice — human, personal, not corporate
- [ ] Implement story-first page flow: person → background → capabilities → work → CTA
- [ ] Surface the personal story: TUM student, family business, real production experience
- [ ] Design system: dark minimal, subtle code aesthetics (not overdone)
- [ ] Dual CTA: contact form + book a call
- [ ] Personal branding elements that show personality and craft
- [ ] Section showing what gets built (complete systems, not isolated features)
- [ ] Visual identity that feels distinctive and memorable

### Out of Scope

- Blog/articles — content maintenance overhead, not core to conversion
- Team/agency framing — this is a solo personal brand
- Light mode — dark is the deliberate aesthetic choice
- Portfolio case studies (v1) — focus on trust and capability first, defer detailed work samples

## Context

- Existing PHP/JS codebase with contact form, Stripe checkout, and basic landing page
- Developer background: Business Informatics @ TUM, PHP production work via family business, full-stack (Rust, PHP, Python, React, Next.js)
- Differentiator: not language-specific, but systems-thinking — connects business logic with technical architecture
- Target client: startups and small businesses that need one person who can build the whole thing
- Mix of cold and warm visitors; some referred, some discovering organically
- Current site problem: too corporate, too generic, zero personality

## Constraints

- **Tech stack**: Existing PHP codebase — redesign in HTML/CSS/JS within current stack
- **Design**: Dark background, minimal layout, subtle monospace/code-adjacent details — never overdone
- **Tone**: First-person, direct, warm but technically confident — reads like a person wrote it
- **Scope**: Single-page or minimal pages — not a complex multi-page app
